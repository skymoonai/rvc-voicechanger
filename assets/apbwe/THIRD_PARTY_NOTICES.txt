Adaptations by RVC Studio:
- Only unchanged ConvNeXtBlock and APNet_BWE_Model generator classes are vendored;
  training discriminators and unrelated utilities are excluded.
- Meta initialization plus strict assign load avoids unused random weight allocation.
- Cached resampling, original lower-band preservation, adjustable upper-band
  residual, left context and a tapered right boundary are added for live RVC.
- Existing RVC inference context and SOLA crossfade are reused, before Soundpad mix.
- Optional bounded CPU subprocess isolates Torch thread settings from RVC.
- No source code from the Vonovox application is included.
